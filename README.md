# Automated_EEG_preprocessing

Code of *Comparative Evaluation of Artefact Removal Methods for Low-Density EEG in Biomedical Applications* (IEEE JBHI, under review).
Please cite the paper (see `CITATION.cff`).

## Requirements

* MATLAB with the Signal Processing, Wavelet and Statistics and Machine Learning toolboxes. The Parallel Computing Toolbox is optional.
* EEGLAB 2022.1 or later, only for `06_real_datasets/Dataset_Stroke_new.m`, `Dataset_Dementia.m`, `Dataset_automaticArtifactRemoval.m` and `09_plots/` (`pop_loadset`, `eeg_interp`, `eegplot`).
* Python 3 with the packages of `01_quality_check/requirements.txt`, only for the quality check of the Stroke recordings.

## Run order

Run the scripts from MATLAB, with the repository folder as current folder. Folders 02, 03, 04, 07 and 09 contain the functions called by the scripts of the other folders; the numbers follow the order of the analysis.

| Folder | Content | What you run |
|---|---|---|
| `01_quality_check/` | Python: quality check of the Stroke recordings | `python DataQualityCheck.py RAW_DIR` |
| `02_preprocessing/` | Common filter, detection of bad channels | called by 06 |
| `03_simulated_data/` | Generation of the semi-simulated EEG | called by 05 |
| `04_denoising_methods/` | WT, ASR, EMD, EMD→WT, ASR→WT | called by 05 and 06 |
| `05_simulated_analysis/` | Semi-simulated data, scored against the clean signal | `Reproduce_simulated` |
| `06_real_datasets/` | Stroke, Dementia and AutomaticArtefactRemoval | `Dataset_Stroke_new`, `Dataset_Dementia`, `Dataset_automaticArtifactRemoval`, `Real_datasets_evaluation` |
| `07_metrics/` | Quality metrics | called by 05, 06 and 08 |
| `08_tables/` | Tables of the paper; computation times; Stroke biomarkers; statistical tests (Python, `statistics/`) | `Paper_tables`, `Computation_times`, `Stroke_biomarkers`, `statistics/*.py` |
| `09_plots/` | Plots of the raw and denoised signals and of the spectrograms | `Plot_raw_EEG` |

The `Dataset_*` scripts apply the five methods to every recording and save the denoised signals, the figures and the comparison with the original; `Real_datasets_evaluation` evaluates the methods on the whole dataset (tables of the paper and sensitivity analysis) and does not save signals.

| Dataset | What to run, in this order |
|---|---|
| Stroke | 1. `01_quality_check/DataQualityCheck.py RAW_DIR` (writes `GoodQuality/`, `BadQuality/` and `EEG_quality_summary.csv`) 2. `Dataset_Stroke_new` (removes the first and the last second, detects and interpolates the bad channels, applies the five methods, saves the denoised files) 3. `Real_datasets_evaluation` with `dataset = 'stroke_saved'` (evaluates the saved files; main Stroke results) and `'stroke'` (the five methods again, with the parameter variants) 4. `Stroke_biomarkers` 5. `Paper_tables` and the tests |
| Dementia | 1. `Dataset_Dementia` (optional: saves the denoised signals and the figures; no channel is interpolated, with 4 electrodes) 2. `Real_datasets_evaluation` with `dataset = 'dementia'` (five methods and parameter variants) and `'p300'` (P300 after denoising, needs the Muse csv) 3. `Paper_tables` and the tests |
| AutomaticArtefactRemoval | 1. `Dataset_automaticArtifactRemoval` (optional: saves the denoised signals, the figures and the computation times) 2. `Real_datasets_evaluation` with `dataset = 'AutomaticArtefactRemoval'` (13 participants; 27, 16, 8 and 4 channels) 3. `Paper_tables` and the tests |
| Semi-simulated | 1. `Reproduce_simulated` (quick test, 2 subjects) or `quick = false; Reproduce_simulated` (the paper: 10 subjects and five artefact amplitudes; set `n_workers` to run in parallel) 2. `Paper_tables` and the tests |

`Paper_tables` writes the tables of the paper from the results of the previous steps, and `Computation_times` the mean and standard deviation of the computation time and memory of every method (the `Dataset_*` scripts record them for each recording; for the semi-simulated data they come from `Simulated_groundtruth_evaluation`); the tests are then run with `python 08_tables/statistics/statistical_analysis.py`, which reads the result files and writes the p-values.

## What the code does, in relation to the paper

The code reproduces the analyses of the paper, from the signals to the tables.

* **Methods.** Five artefact-removal methods (wavelet transform, ASR, EMD and the two hybrids EMD→WT and ASR→WT) are implemented in `04_denoising_methods/` with the settings of the paper and applied in the same way to all datasets.
* **Datasets and preprocessing.** A semi-simulated EEG generated by the code, for which the clean signal is known, the public AutomaticArtefactRemoval dataset, and the Stroke and Dementia recordings, which are patient data and are not in the repository. The preprocessing differs between datasets as described in the paper: filtering for the semi-simulated and AutomaticArtefactRemoval data, automatic quality check and interpolation of bad channels for Stroke, and no interpolation for Dementia (4 electrodes).
* **Evaluation.** With the clean signal (semi-simulated data): SNR, relative error and correlation. Without a reference (real datasets): preservation of the signal (amplitude, spectrum, correlation structure between channels, symmetry). For Stroke, the relative band powers and ratios used as biomarkers; for Dementia, the P300 after denoising. A sensitivity analysis varies the main parameters of each method and the amplitude of the artefacts.
* **Tables and statistics.** `Paper_tables` collects the results in the tables of the paper; `08_tables/statistics/statistical_analysis.py` runs the Friedman test and the paired Wilcoxon tests with Bonferroni correction.
* **Plots.** `09_plots/` shows the raw and the denoised signals and their spectrograms.

All the results are written to `results/`.

## Data and folders

The folders `data/` and `results/` are created inside the repository (git ignores them); if folders with these names exist next to the repository they are used instead. They can also be set in `cfg_path.m` or with environment variables (see the top of `cfg_path.m`).

| Folder | Content | Available |
|---|---|---|
| `data/SimulatedEEG` | `EOG_all_epochs.mat` and `EMG_all_epochs.mat` of EEGdenoiseNet; the EEG is generated by the code | public (downloaded automatically) |
| `data/AutomaticArtefactRemoval` | `s01 ... s13`, each with `s01.set` etc. | public: https://github.com/sskarthigadevi/dataset-automaticArtifactRemoval |
| `data/Dementia` | `ID*/*preproce*.set` and `*Muse_output.csv` | not shareable |
| `data/Stroke` | `sub-XXXX/sub-XXXX_OriginalInterpolated.set` and `sub-XXXX_<method>_denoised.set` | not shareable |
